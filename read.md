# Git
What is it? A version control system that tracks changes in files and code.
Why use it? To save versions of projects, collaborate with others, and restore previous versions.
Who created it? Linus Torvalds.

# Linux
What is it? An open-source operating system kernel.
Why use it? It's free, secure, stable, and widely used on servers.
Who created it? Linus Torvalds

HTTP, HTTPS, IP, and SSH
# HTTP
HyperText Transfer Protocol.
Used to transfer web pages between browsers and servers.
# HTTPS
Secure version of HTTP.
Encrypts data using SSL/TLS.
# IP
Internet Protocol address.
Unique address that identifies a device on a network.
# SSH
Secure Shell.
Used to securely connect to and manage remote computers.

# VS Code
What is it? A free code editor developed by Microsoft.
Why use it? To write, edit, debug, and manage code efficiently.
